# LH Nautical - Desafio Técnico

Repositório com a resolução completa do case técnico da LH Nautical,
organizado por questão conforme o enunciado do desafio.

## Estrutura

- `data/raw/` — CSVs originais fornecidos, sem tratamento
- `questoes/` — uma pasta por questão do desafio, com código e outputs
- `docs/` — decisões técnicas e dicionário de dados
- `relatorio_final/` — material complementar final (relatório consolidado + visualizações)

## Como rodar

Ver instruções específicas dentro de cada pasta de questão.

## Relatório Final

O relatório consolidado do desafio está em [`relatorio_final/`](relatorio_final/), organizado por frente de trabalho (EDA, Tratamento de Dados, Análise de Clientes, Análise de Vendas, Previsão de Demanda e Sistemas de Recomendação), com fluxogramas do pipeline e gráficos de apoio às principais conclusões de negócio.

- `relatorio_final_completo.docx` — documento final, pronto para leitura
- `relatorio_final.md` — documentação de como o relatório foi gerado (metodologia e scripts)
- `gerar_relatorio.js` / `gerar_graficos.py` — scripts que geram o documento e os gráficos
