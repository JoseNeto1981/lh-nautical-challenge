# LH Nautical - Desafio Técnico

Repositório com a resolução completa do case técnico da LH Nautical,
organizado por questão conforme o enunciado do desafio.

## Estrutura

- `data/raw/` — CSVs originais fornecidos, sem tratamento
- `questoes/` — uma pasta por questão do desafio, com código e outputs
- `docs/` — decisões técnicas e dicionário de dados
- `dashboard/` — material complementar final (painel de visualizações)

## Como rodar

Ver instruções específicas dentro de cada pasta de questão.
